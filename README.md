# ナオコバースデー杯

タップだけで遊べる、1対1のシンプルなバレーボールゲームです。

## 遊び方

- ボールが「YOU」に近づいたタイミングで `タップ！`
- 7点先取
- 得点は、体育館内のめくるタイプの得点ボードにそのまま反映されます
- PERFECT返球ほどCPUが取りにくくなります

## 難易度

CPUの返球判定は **1球につき1回だけ** です。

目安:
- 普通の返球: CPU返球率 約70%
- 良いタイミング: 約50%
- PERFECT: 約30%

以前の「範囲内で毎フレーム抽選してしまい、実質ほぼ100%返球になる」問題は修正済みです。

## GitHub Pagesで公開

1. このフォルダの `index.html` / `style.css` / `script.js` をGitHubリポジトリにアップロード
2. GitHubの `Settings`
3. `Pages`
4. `Deploy from a branch`
5. `main` / `root` を選択して保存

しばらくするとURLが発行されます。
